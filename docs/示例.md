# Markdown 写作

写下文字，排版随之呈现。**加粗**、*斜体*、~~删除线~~ 和 `行内代码`，都可以直接用 Markdown 输入。

## 保持熟悉的写作习惯

光标进入加粗或链接时，语法会显示出来，方便修改。离开后，它们恢复成阅读时的样子。

> 让注意力留在文字上。

- 一份文档，一页干净的纸
- 多标签页与独立窗口
- 自动保存和本地草稿恢复

## 表格与代码

| 操作 | 快捷键 |
| --- | --- |
| 保存 | Ctrl + S |
| 源码模式 | Ctrl + / |
| 新建窗口 | Ctrl + Shift + N |

## 公式

行内公式 $E = mc^2$，也可以单独写成公式块。

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$
